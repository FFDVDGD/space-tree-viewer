JSON 格式与扫描说明
{
  "name": "项目工作量",
  "unit": "小时",
  "children": [
    { "name": "设计", "value": 24 },
    { "name": "开发", "children": [
      { "name": "前端", "value": 48 },
      { "name": "后端", "value": 80 }
    ]}
  ]
}

子项使用 name / value / children，父级未填 value 时自动求和。容量数据设 unit 为 bytes，也可导入此前的磁盘 JSON 快照。多个文件须使用相同单位。
